Primary objective:
ensure all existing systems interact in a predictable, non-chaotic, non-compounding way under real usage.

Focus on interaction stability, not capability.

1. System Interaction Audit (Lightweight)

Identify and resolve unintended interactions between:
- playstyle system
- habit system
- risk scoring system
- zone classifier
- planner fallback logic
- LLM deterministic fallback
- task queue eviction logic

Goal:
no subsystem should override another in unexpected ways.

Priority order must be explicit and enforced:
CRITICAL runtime safety > Arbitrator > Planner > Cognitive Router > LLM fallback > ambient systems

2. Global Behavior Priority Rule

Implement a single unified priority rule evaluation step:

At every decision point, enforce:
- safety overrides everything
- combat/risk overrides idle/humanization
- planner overrides ambient behaviors
- deterministic fallback overrides LLM outputs
- queue eviction never changes task semantics

This is not new architecture — just enforcement clarity.

3. Conflict Detection Logging

Add lightweight logging for when:
- two systems attempt conflicting actions
- a task is overridden by another subsystem
- a fallback replaces an LLM decision
- a habit biases against a planner decision

Log should be:
- single line
- concise
- tagged with subsystem names

No verbose tracing.

4. Determinism Enforcement Layer

Ensure that in debug mode:
- same inputs produce same task sequences
- same state produces same playstyle decisions
- same zone + risk + mode produces same behavioral outputs

If randomness is used, it must be:
- seeded
- isolated
- reproducible

5. Fallback Consistency Rules

Ensure all fallback paths converge to a small set of behaviors:
- follow_player
- idle_safe
- mine_resource
- return_home
- stop

No ad-hoc fallback behaviors outside these core actions.

6. Queue Eviction Safety Check

Ensure queue eviction:
- only removes LOW/NORMAL tasks
- never removes CRITICAL/HIGH tasks
- never changes ordering of active task execution
- never triggers cascading planner retries

7. Playstyle + Habit Interaction Fix

Ensure playstyle and habits:
- only adjust weights
- never directly force actions
- never override planner output

They should bias probabilities, not command execution.

8. Risk System Authority Fix

Risk system must:
- only escalate or suppress actions
- never directly enqueue non-safety tasks except return_home/escape/flee

It is a modifier, not a planner.

9. Debug Mode Trace Alignment

When debug mode is enabled:
log a single unified “decision trace” per tick:

inputs:
- zone
- risk
- mode
- playstyle
- active task

output:
- chosen action
- reason (short tag only)

No verbose reasoning chains.

10. Cost Discipline

Strictly enforce:
- no new subsystems
- no refactors beyond enforcement fixes
- no architecture expansion
- no speculative improvements
- no multi-file rewrites unless required for correctness

Only alignment, constraint enforcement, and interaction safety fixes.

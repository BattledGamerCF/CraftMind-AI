1. Deterministic Debug Mode

Add a global debug flag in config:

When enabled:
- disable random humanization timing variance
- log all task transitions clearly
- log all planner decisions (compact)
- log all LLM intents before execution
- log arbitrator decisions (why tasks were accepted/rejected)
- suppress ambient noise behaviors

Goal:
reproducible bot behavior for debugging.

2. Structured Error Reporting

Standardize all errors into a single format:

- subsystem
- error type
- human-readable explanation
- suggested fix
- severity level

Apply to:
- provider failures
- planner failures
- executor failures
- persistence failures
- config failures

Avoid raw stack traces as primary output.

3. Startup Health Check System

On boot, run a single consolidated health check:
- config validity
- provider availability
- persistence directory access
- model reachability (if possible)
- core system initialization integrity

Output should be:
- concise summary
- pass/fail per subsystem
- no spam logs

4. Plugin-Safe Boundaries (Lightweight)

Do NOT build a plugin system.

Instead:
- clearly mark extension points in code
- ensure executors are registry-driven
- ensure planners are registry-driven
- avoid hardcoded cross-system dependencies

Goal:
future extensibility without rewrites.

5. Performance Guardrails

Add lightweight protections:
- max tasks per tick
- max LLM calls per minute
- max planner expansions per cycle
- debounce repeated perception triggers
- avoid redundant zone recalculation
- prevent memory growth spikes

These must be configurable.

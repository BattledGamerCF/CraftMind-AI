Primary objective:
make the bot capable of surviving and functioning autonomously for extended multiplayer sessions with minimal supervision.

Priority systems:

1. Lightweight Persistence

Implement compact persistence for:
- home location
- trust data
- semantic memory summaries
- active cognitive mode
- current planner objective
- inventory preferences
- discovered waypoints

Persist only compact high-level state.

Do NOT persist:
- executor internals
- perception snapshots
- large telemetry logs
- pathfinding state

Persistence goals:
- survive reconnects
- survive process restarts
- restore continuity cleanly

Use lightweight JSON persistence only.
Avoid database complexity.

2. Equipment Progression

Implement lightweight survival progression heuristics:
- craft wooden tools if missing
- upgrade to stone tools when possible
- upgrade to iron tools opportunistically
- replace broken tools
- maintain at least:
  - one pickaxe
  - one weapon
  - food reserves

Do NOT build a giant crafting planner yet.

Use simple heuristic progression.

3. Chest / Storage Awareness

Add basic storage intelligence:
- detect nearby chests
- remember chest locations near home
- deposit excess resources
- withdraw useful supplies
- avoid filling inventory permanently

Simple rules:
- keep essentials
- store excess blocks/resources
- preserve tools/food/armor

Avoid complicated inventory optimization systems.

4. Waypoint Memory

Add semantic waypoint support:
- mines
- villages
- forests
- dangerous zones
- farms
- storage areas

Waypoints should store:
- position
- type
- short summary
- optional danger rating

Use lightweight semantic summaries only.

5. Basic Crafting Intelligence

Implement compact crafting capability:
- craft planks from logs
- sticks from planks
- torches if coal exists
- tools from available materials
- bread if wheat exists

Only craft when useful.

Avoid excessive crafting churn.

6. Exploration Improvements

Improve exploration practicality:
- avoid revisiting recently explored areas
- prefer daylight exploration
- remember dangerous regions
- bias toward useful biomes/resources
- stop exploring when inventory is nearly full

Use lightweight heuristics.
No large terrain-analysis systems.

7. Companion Behaviors

Improve player companionship subtly:
- avoid crowding players indoors
- stay visible but not obstructive
- move aside when players mine/build nearby
- follow smoothly around corners
- occasionally acknowledge nearby events

Keep behaviors subtle and low-frequency.

8. Long-Session Stability

Add safeguards for:
- runaway memory growth
- waypoint spam
- trust spam
- planner deadlocks
- idle loops
- repeated stuck recovery

Implement pruning/compression where appropriate.

9. Telemetry Cleanup

- standardize telemetry response structure
- remove duplicate fields
- expose compact summaries
